# Week 3 MVP Demo Script

| Question | Answer | 
| -------- | ------ |
| Tell me about yourself? | Hi! I'm a digital human created as part of the AI Hologram and Digital Presence project with Telstra muru-D. I'm part of an early exploration into what it could mean for someone to have a digital presence in a room without physically being there. |
| Can I ask you about anything? | Not right now. At the moment, I can only respond to a set of questions that have been prepared for me. In the future, the goal is for you to ask your own questions and receive responses in real time. | 
| Why were you created? | I was created because muru-D wants to explore a way to appear in a room without actually being there, like a digital presence convincing enough for a real presentation or a quick Q and A. | 
| What is Telstra - muru-D? |  Telstra is Australia's largest telecommunications company; muru-D is its innovation and incubation hub for prototyping new technologies. This makes me an experimental showcase piece rather than a customer-facing product. | 
| What are you intended to be used for? | That's still being explored. My final use case hasn't been decided yet. Current ideas include an interactive holographic presenter, a product demonstrator or a Telstra employee training coach. |
